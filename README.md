### 🚀 What I Do

- **Computer Vision & Biometrics:** Developing object detection and biometric ROI localization systems (SSDLite, Faster R-CNN, YOLO11-UIB) with PyTorch–ONNX numerical parity verification and CPU latency profiling.
- **Time-Series & Financial Forecasting:** Designing multi-branch neural forecasters (GUMNet, HybridTriNet combining KAN, GRU, and Patch Transformers) with quantile risk modeling and strict chronological validation.
- **Document AI & Multimodal RAG:** Building layout analysis pipelines (OCR, table extraction, document deskewing) and enterprise retrieval engines with pgvector, BM25, and neural rerankers.
- **Reproducible MLOps:** Packaging versioned model weights, scalers, SHA-256 metadata, and standalone CPU inference scripts for open inspection on Hugging Face Hub.
